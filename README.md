# Convoy-Defender
A short 2D Java game that reinvents Space Shooter into a convoy defence game.
The objective is to protect the convoy from an oncoming wave of enemies. You win if the minimum amount of convoys required have passed safely. You lose if you have either lost all your lives or failed to prevent the enemies from destroying at least half of the convoy.
The convoy will send up a number of collectible items:
1.Hearts will add a life.
2.Batteries will restock your ammunition.
3.Blue orbs will allow you to deploy a shield.
Shields will kill an oncoming enemy upon contact, helping you defend large portions of the convoy. They last for up to 5 hits before disappearing.
In later levels, blue variants of the enemy will appear, who will move more quickly and can damage the shields more easily.
The checkbox at the main menu allows for a second player. As this is a co-op game, supplies are shared between both players.
Controls:
W,A,S,D (Player 1) / Arrow keys (Player 2) to move
Spacebar (Player 1) / Enter key (Player 2) to shoot
Q (Player 1) / Shift key (Player 2) to deploy shield
